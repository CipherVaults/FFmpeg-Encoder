Later preparation again excludes all generated outputs by default, including newly generated generations.

Expert codec/backend/preset/CRF-or-CQ and current bit-depth behavior stay primary. Current tested defaults stay unchanged. Before preparation expose deterministic production encoder contributions and conceptual preset/quality explanation. Preset help must reveal actual native preset arguments (including SVT), distinguish CRF/CQ and backend semantics, and share canonical configuration with production argument construction. Tested Default reveals everything it actually applies, populates ordinary editable controls and introduces no hidden magic options. Renderer must display the prepared representation used for execution, not independently reconstruct a command. Retain narrow validated IPC, no arbitrary argv submission/process execution/filesystem authority. Use an exact argument list or faithful Windows quoting; label approximations/templates honestly. If the owned temporary output path is assigned only at execution, clearly identify that sole placeholder rather than falsely claiming a ready-to-run exact command; expose actual invocation when assigned. Do not allocate cleanup authority from display data.

Help must support hover plus keyboard focus or accessible details controls, remain readable, and avoid covering editable controls.
