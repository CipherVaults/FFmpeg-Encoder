## Draft/default semantics

App Settings saves defaults for **new batches**. An existing draft retains its batch snapshot until the user invokes a visible Apply app defaults to this batch action; retain per-file overrides unless that action explicitly includes resetting them. Per-file controls show effective values and origin. Changing batch defaults changes only inheriting draft files, increments draft revision, and invalidates preparation for affected jobs. File override/reset follows the same rule. Do not mutate queued/running/frozen plans.

Full is initially selected for every newly admitted file. Time Range belongs to file identity, not the current profile. Explicit Apply range to selected files validates each duration independently and reports incompatibilities without silently clamping. Restart restores ordinary validated defaults/locations only; drafts may be recreated but no prepared plan, source authority, omission permission or generated-output grant survives.

Temporary omission decisions bind fileID+sourceFingerprint+draftRevision+specific stream identity+target operation. A generated-source grant also binds recognized outputID and exact prepared state. Filtering, changing tabs, expanding details and reviewing logs never issue or invalidate authority. A meaningful operation edit does invalidate it. No global ignore/allow-all switches.

## State transitions

Draft(unprepared) → Preparing → Prepared or Attention(error/unsupported/decisions needed). A revised draft invalidates only its associated preparation; immutable prior results stay readable. Start checks exact prepared ID/revision, current source/folders/capability and creates queue snapshot. Queue → Running → Validating → AssessingSource → Publishing → Saved/SavedWithWarning/Skipped/Retained/Failed. Every durable transition has an incident; progress is bounded/rate-limited separately.

Cancellation stops future admission/queued starts, requests current owned child stop and waits for close. Before media completion, existing owned-incomplete cleanup applies. After output validation, cancellation retains the bound complete stage without publishing; after publication it never deletes output. A failed source assessment never grants a fresh cache identity. Recovery reports interrupted session and retained artifacts without automatically executing or deleting anything. Reprepare is a new main-owned authority decision.

## Audio and timeline amendment

Encode Full default is compatible stream copy and retains old argv path. Encode non-Full default is `precision-aac`: decode/trim the entire selected audio interval and re-encode AAC-LC, preserving channel layout and sample rate where supported. Initial qualification targets mono128kb/s, stereo320kb/s,5.1 at512kb/s,7.1 at768kb/s; unsupported/unknown layouts or sample rates require a precise explanation, never automatic downmix/resample. These are functional quality-conscious engineering values, not proven inaudibility or benchmark recommendations. Actual supplied stereo rates span about100–320kb/s at44.1/48kHz; do not infer uniform192kb/s. The policy must be tested on shipped encoder/container cells before enablement.

Advanced overrides: precision AAC bitrate from a bounded validated range; precision FLAC where Matroska supports the exact source layout/rate; explicit packet-copy alternative only for qualified range/container/stream cells. FLAC is lossless relative to decoded samples in its supported path, not a restoration of a lossy original capture. User-facing wording must not call AAC lossless or identical. Unknown/incompatible override blocks preparation rather than silently choosing another codec.

RequestedRange is a presentation interval `[startUs,endUs)` relative to the selected input video origin. EffectiveVideo records actual retained first/last framePTS and duration; late-seek preroll is decoded then discarded accurately. EffectiveAudio per stream records original offset, requested decoded sample interval, actual first/last retained sample, output timestamp mapping, codec delay/padding and observed decoded bounds. Preserve meaningful source A/V offsets; do not independently zero every stream and erase them. ExpectedOutput carries validation tolerances with their measured provenance, not a universal100ms precision bound. Q must qualify decoded boundary and end-to-end synchronization tolerances using deterministic markers and real native evidence before declaring support.

Packet-copy mode separately discloses effective packet boundaries/rounding; no promise of sample-exact selection. Remux remains Full only. Chapters intersect/rebase selected interval. Subtitle overlap/state is codec-qualified; an unsupported range combination requires specific stream handling, never silent loss.
