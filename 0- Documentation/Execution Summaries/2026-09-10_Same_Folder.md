## Implemented safety model

Main captures every supported top-level source pathname and reliable filesystem identity before workers start. Those destinations remain forbidden after source disappearance; hard-linked aliases are excluded and symlinks fail closed. Directory dev/ino/birthtime and canonical paths are rechecked. Same-folder operation additionally requires the bounded helper to verify local Fixed/NTFS storage. Distinct-folder operation retains its existing exclusive-copy fallback where atomic links are unavailable.

Provenance is classified before a destination skip or deeper frame sampling. Reserved global tags FFMPEG_ENCODER_PROVENANCE=1 and FFMPEG_ENCODER_OUTPUT_ID=main-generated UUID identify new outputs. Partial, unknown, malformed, duplicated or misplaced reserved tags cannot become ordinary sources. Raw ffprobe JSON rejects duplicate keys, including parent containers that could otherwise erase markers during JSON.parse. Inspection normalization policy is now2: earlier development cache evidence deliberately misses once, rather than bypassing the stronger parser. SDR/HDR sampling and media settings remain unchanged.

All six historical suffixes classify unmarked files as Possible previous output independently of available hardware. Treat as original is a narrow main/preload action bound to current plan and sparse identity, revalidated before encode and expired by reprepare/change. Marked/index-recognized outputs cannot be overridden. Strong source identity now supports provenance/overrides even when persistent cache reuse is unavailable; cache storage eligibility still controls reuse only.

Separate provenance-v1 stores checksummed immutable intent/published records using synced owned temporaries and exclusive atomic links. Bounds:10,000 namespace entries,32MiB total,16KiB per record. No eviction deletes history. Required intent failure prevents encoding/publication. Final-record failure preserves the valid published file and intent with a pending notice. Startup read-only recovery inspects at most128 pending intents, distinguishes matching/absent/unrelated/uncertain and reports remaining inventory; it never overwrites, retries, republishes, relabels or deletes media. Completed pairs support identity recognition without repeated startup media probing.

An exact createStage object carries private in-process cleanup authority. Successful encoder close is followed by sealStage BEFORE ffprobe; publication rechecks directory and file identity/content stamps and source reservations. Same-folder atomic-only link failure never falls back to copying. A late detected path-to-link race preserves the uncertain destination. Cleanup checks bound identity and protected input identities; journal records never grant cleanup authority.

## Local engineering adjustments and limits

A cancelled/failed encoder can leave a temporary file that was never identity-bound. Adopt-and-delete would risk removing a replacement, so K retains it with an explicit per-file reason/path. The hidden staging directory is excluded from top-level discovery and restart remains available after children close. Successfully bound owned files are cleaned normally. No broad sweep or journal-driven deletion was added. This strengthens uncertain cleanup safety at the cost of possible retained temporary disk usage; it does not switch to -y or background encoding.

Node's path-based hard-link/unlink APIs do not provide a fully adversarial atomic identity-conditional primitive. Checks and post-link detection cover ordinary cooperative filesystem changes; do not claim every hostile same-user race is impossible. Marker UUIDs and local records identify outputs, not cryptographic authorship. Sparse identity is not whole-file equality. Ordinary renames/copies retain markers; matching indexed identity covers supported rename cases. If external edits remove marker, identity and suffix/index evidence, perfect historical attribution is impossible. Rollback0.5 does not understand new provenance: use separate output folders and original-only inputs with the old binary; preserve the separate0.6 state for return.
