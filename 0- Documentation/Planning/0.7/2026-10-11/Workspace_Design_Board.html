Three directions, one recommendation

1 · Tabbed workbench

Encode · Remux · Activity · Settings FILES │ EDIT SCOPE │ OUTPUT ──────── Current job / Cancel ────────

Recommended. Stable navigation, a clear editing scope and one shared result model. Keeps batch work and careful per-file exceptions equally visible.

2 · Library first

FILES + CONTENT DETAILS ───────────────────────── Open selected file inspector → Operations in a side drawer

Strong for browsing, but batch defaults become less discoverable and more settings live behind a drawer.

3 · Task canvas

ENCODE / REMUX Source → Transform → Destination Review one task at a time Activity in a separate lane

Good at small sizes; weaker for comparing many per-file overrides. Avoid making this a beginner wizard.

Archive recipe explanation

P7 is the native preset. UHQ is the tune. Full-resolution multipass adds analysis cost. VBR-CQ with editable CQ29 controls quality. Four B-frames and B-reference “each” are additional settings.

The canonical recipe supplies the exact current values and argument fragments. CQ29 is an existing measured starting point, not universal x265 equivalence or a promised size reduction.

At 640 × 480

One vertical document, collapsible file list and a persistent selected-file identity. Avoid multiple trapped scroll regions. Keep actions reachable without overlays covering fields.

Tabs use keyboard activation. Slider handles have exact-entry alternatives. Status uses text and symbols, never color alone. Help remains focusable and readable.

Subtle orientation cue

Thin section-edge accent shifts toward mint on hover and focus-within. No glow or animated background. Focus rings remain distinct from hover and selection.

Empty / unsupported-only

Explain allowed sources and specific refusal reasons. Preserve an incident even when no encode starts. No alarming wall of absent-GPU errors.

Stale preparation / mixed batch

Mark affected files “Reprepare required.” Retain unaffected results and visible counts. Never start stale queued settings.

Logging or recovery failure

“History could not be fully saved.” Keep media outcome separate. Interrupted sessions offer evidence, not automatic replay or cleanup.

Design decisions for review: adopt the tabbed workbench; keep the native Windows title bar; preserve visible expert controls; use scoped defaults and per-file details. Production behavior, native accessibility and owner visual acceptance require later authorized implementation and evidence.
