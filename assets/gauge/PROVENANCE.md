# Gauge application icon (0.6 Beta packaging)

`gauge-app.ico` is the seven-frame Windows icon of the owner-selected Gauge mark.
Its largest (256 px) frame matches `assets/logo-gauge-2026-11-14/gauge-win-midtone-256.png`
at commit 1b9838a0c4a9379ef36032ddea4c422e66aaea9b. The same ICO (SHA-256
b2bbcc2675f6d99b5a985f838bdd9e2128c202f109c10890fe41e00cba86a620) is used by the
0.7 Alpha packaging rehearsal. It is applied only through `packaging.config.cjs`
(executable, window and taskbar icon) and the Windows installer; no application
logic changes. The artwork is the project's own mark; no third-party license applies.
