# Isolated inventory-only proposal, unbound

The script collects only named build-tool dpkg versions, hashes of their resolved /usr/bin tools, hashes of ELF headers, and two allowlisted image labels. It does not dump the environment, filesystem, package manager configuration, credentials or raw diagnostics. No install, build, media, workflow installation, push or dispatch occurred.

Authenticated correspondence is deliberately exact: fixed official noble/noble-updates/noble-security InRelease files verified by installed Ubuntu archive keyring and gpgv; SHA256/size-bound main/universe Packages.xz; exact installed name/version/architecture tuple only. Old installed versions absent from those indexes remain unresolved. It never chooses a newer candidate to make the report green. Missing gpgv/keyring or index validation failure yields a bounded failure code, not signature bypass. No keys are imported. This is archive correspondence, not proof that a runner's installed file equals the archive contents.

Proposal bounds: 6-minute job,270-second external timeout with5-second kill grace,240-second subprocess admission,20-second commands/network operations,192MiB total compressed indexes,64MiB each,256MiB decompressed each and post-capture stdout/stderr size checks. Subprocess output is buffered until exit; the size check is not a streaming memory ceiling. Only fixed trusted inventory commands run, with the20-second timeout; no downloaded code executes. Large indexes remain memory-only; temporary InRelease files are removed. Exact source/workflow predecessor is UNBOUND and refuses execution. Preserve the report durably before3-day artifact expiry.

Scope is the initial named-tool inventory. It explicitly reports dependencyClosureComplete=false: full transitive installed compiler/runtime/build-tool dependencies and package ownership of resolved tools must be reconciled before a later recipe/build approval. Do not treat inventory-mapped as build-ready. Snapshot acquisition of old packages, deb download or installed-file reconstruction is not implemented by this first report. No package install permission is implied.

Review before any integration: exact execution paths, command/output/time caps, signed metadata parser, event scope and report schema. The source and workflow remain isolated here, not in frozen081. The workflow text assumes a later reviewed scripts/ubuntu-toolchain-inventory.py location; that binding must be finalized before execution. Fifteen inert tests passed, including mocked exact signed-index correspondence, missing version, signature/hash/size refusal and dpkg installed-state checks; they do not establish hosted behavior or trust metadata on this Debian host.

Redirects are now refused by the urllib redirect handler before any redirected request is constructed/opened, including redirects to another official path. This deliberately retains the prior all-redirect refusal policy rather than broadening accepted destinations. The final response URL assertion remains defense in depth. Inert tests cover 301/302/303/307/308, external/HTTP/official/relative destinations and absence of a second opener contact; no network was used.
