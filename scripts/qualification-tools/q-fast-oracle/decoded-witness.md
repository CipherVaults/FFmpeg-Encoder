# Decoded witness, test only
`read_decoded_witness(bundle,pins)` has no runner, IPC, product verifier imports or execution/release permission. Input is an independently established pair of SHA-256 media identities, exact original source-call and target-report hashes, one pinned runtime manifest, and relocated regular local paths to the immutable media and raw pipes. Never compute the trusted pins from a supplied witness and then call it independently authenticated. Original logged paths link each approved argv to its stream and probe, but are not projected. The normal116 adapter supplies named sample bindings only.

Complete ordered video framemd5 rows are checked against independently parsed sample table presentation intervals, as rational values, with exact actual counts. AAC s32le PCM is hashed in full and per channel; inferred start, extent and continuity are restricted to the single unity edit, 1024-sample priming, contiguous sample table, exact packet clock and expected PCM count in this finite MP4 envelope. The independent physical readback verifies every packet position/size/hash and mdat coverage. Only decoded values and observed presentation semantics determine equal/different; compressed packet hashes and codec config are separate corroboration and can differ without declaring a decoded difference. Returned track language and default are only bounded observed facts, not all-container metadata validation. Unknown/absent/mismatched evidence raises WitnessUnknown, which a caller must map to unknown not different. No GUI, hardware, performance, security audit, material outside this narrow H.264/AAC-LC/MP4 envelope, or runtime re-attestation claimed. Archived runtime evidence is not a live executable check.

Portable: `python3 -B tests/decoded-witness.test.py`. For exact archived tests, set Q_DECODED_ORACLE_ROOT to the directory containing oracle-report.json and original output pipes; Q_DECODED_SOURCE_RECEIPTS to the held input directory containing calls.json, original media/probes/decodes; and Q_DECODED_QA_ROOT to the independent recovered QA archive root. All commands are offline.
