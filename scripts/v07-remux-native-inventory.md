Unlisted ISO boxes, Matroska element IDs and PMT descriptor tags refuse. Every listed PMT descriptor has an active transport-inventory rule, including frame-compatible stereoscopic descriptor 0x35. The independent test registry is extracted from pinned FFmpeg 946fcce07b (MOV parse table, Matroska constants and TS descriptor constants); it also explicitly includes ISO stvi and TS 0x35. This is a completeness floor for the pinned demuxer, not the complete registry of every published format extension.

Ordinary colour/aperture/dependency extensions are compared. All-zero version-0 SDTP entries equal absence, with exact sample-count/FullBox validation; any nonzero dependency bit remains exact. Copy and dither-copy ignore operand colours; unsupported composition modes refuse. Empty EBML integers, floating-point values and strings take their schema defaults (or the EBML zero/empty default where none is declared).

Native chapter language is limited to implicit English, and chapter navigation must be flat: the pinned muxer does not carry other language selections or nested ChapterAtoms. Independent DefaultDecodedFieldDuration declarations refuse. Native chroma coordinates must either both be unspecified, or jointly corroborate an exactly carried codec chroma location; partial declarations refuse.

Both finite and unknown-sized Matroska Clusters have a schema-level header walk. Native block track/timestamp/flag headers bind canonical previous-block references and terminal AAC padding. The header walk skips coded bodies; the separate access-point check reads bounded NAL/OBU framing and picture headers, never scans coded bodies for element boundaries. Unknown IDs and unsupported encrypted, virtual or additional block interpretations refuse before Ready. Segment-level siblings end unknown Clusters, while global Void/CRC-32 do not. Only Segment/Cluster may have unknown sizes.

For record budget R, the header caps are 16R+8192 elements, 32R+65536 header bytes and depth 12, within the existing 256R+8MiB metadata-byte budget. Cancellation and deadline checks run at each header/loop. With R=20000, caps are 328192 elements and 705536 header bytes. Long files receive the normal service proportional record budget; this remains a finite header-density limit.
