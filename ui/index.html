    Using the workbench
    1. In Encode, choose input and output folders. Your codec/backend profile, preset and CRF/CQ controls remain directly editable.
    2. Review the batch. Expand a file for preservation notices, generated-output identity and the resolved FFmpeg arguments.
    3. Start selected files. Jobs shows the current batch; progress and cancellation stay available across workspaces.
    4. Inspect past events in History. Local details can contain private paths; preview selected redacted records before sharing.
    Generated outputs remain excluded unless you deliberately authorize specific files for re-encoding. Candidate quality numbers are encoder-specific; matching CRF/CQ values do not imply matching perceptual quality.
    App Settings stores defaults for future batches separately from remembered encoder controls. No settings reset deletes original media or completed outputs.
