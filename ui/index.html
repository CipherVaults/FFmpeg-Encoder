      Using the workbench
      1. Choose input and output folders in Encode. Codec/backend, native preset and exact quality remain directly editable.
      2. Prepare the batch to inspect effective settings and file eligibility. Use Inspect for a file's preservation notices, generated-output identity, processing overrides and resolved FFmpeg arguments.
      3. Review selected files beside Start, including files hidden by filtering or collapse. File focus is independent of batch membership.
      4. Start eligible selected files. Current Jobs follows the queue, measured progress and cancellation. History keeps past records without resuming work.
      Settings scope and preparation
      Encoder controls apply to the Encode batch. Batch processing defaults affect inheriting files; the inspector contains this file's overrides. App Settings saves defaults for future batches. Existing drafts adopt saved defaults explicitly, and prepared, queued or running snapshots never change through navigation.
      Range, resolution, audio and HDR choices are requests subject to main validation. Read the resulting file status and effective output; an available field does not prove an executable route.
      Generated sources and quality
      Generated outputs remain excluded unless you deliberately authorize specific files for re-encoding. Each further lossy generation can reduce quality. Filtering or selecting a file does not grant that permission.
      Quality numbers are encoder-specific. Matching CRF/CQ values do not imply matching perceptual quality. Tested Default and Archive Quality populate the ordinary editable controls; inspect their additional options.
      Saved output, retained work and private history
      A file is saved only after validation, source checks and protected publication. Retained temporary work is a separate outcome. Use only the output actions offered for that exact result.
      History can contain private paths and metadata. Preview selected redacted records before sharing. Settings resets preserve original media and completed outputs.
